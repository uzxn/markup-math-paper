# mmp - Markup Math Paper

mmp 是一个将特定标记文本转换为 HTML 的命令行工具，专注于高中数学试卷的快速排版。

不想写文档。

## 使用

```bash
mmp 试卷文件名.任意扩展名
```

- 输出文件为 `试卷文件名.html`
- 需要程序同目录下的 `template.html`

## 模板

`template.html` 是生成的试卷页面的**外壳**。mmp 会读取该文件，将解析后的试卷内容插入到 `[placeholder]` 所在的位置，然后输出完整的 HTML。模板中可自定义 CSS，而源文件只专注于试题文本。

默认提供的模板已基本满足高中数学试卷的排版需求。
