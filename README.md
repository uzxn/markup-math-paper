# mmp - Markup Math Paper

mmp 是一个将特定标记文本转换为 HTML 的命令行工具，专注于高中数学试卷的快速排版。

这种标记文本与 Markdown 类似，但**不支持完整 Markdown 语法**，仅借用了 Markdown 的常用符号（如 `#`、`*`、`>`、`1.` 等）来定义语法，以降低学习成本。

## 语法

请按以下示例编写：

```markdown
# 试卷标题（20XX 年 XX 考试）

（空行会被忽略）

## 小节标题（注意事项：...）

> 一级缩进
> > 二级缩进
> > > 三级缩进
> > > > 四级缩进

## 小节标题（一、选择题：本题共 8 小题 ...）

* 题干内容（无需写题号，工具会自动编号）
1. 第一列的短选项一
2. 第二列的短选项二
3. 第三列的短选项三
4. 第四列的短选项四
---（换行）

* 题干内容
1. 第一列的长选项一长选项一长选项一
3. 第三列的长选项二长选项二长选项二
---（换行）
1. 第一列的长选项三长选项三长选项三
3. 第三列的长选项四长选项四长选项四
---（换行）

这是普通段落，不会有任何缩进。
```

## 使用

```bash
mmp 试卷文件名.任意扩展名
```

- 输出文件为 `试卷文件名.html`
- 需要程序同目录下的 `template.html`

## 模板

`template.html` 是生成的试卷页面的**外壳**。mmp 会读取该文件，将解析后的试卷内容插入到 `[placeholder]` 所在的位置，然后输出完整的 HTML。模板中可自定义 CSS，而源文件只专注于试题文本。

默认提供的模板已基本满足高中数学试卷的排版需求。
